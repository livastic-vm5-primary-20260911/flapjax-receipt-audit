Methods and source boundary

The GoPlus BSC token-security endpoint reports 181 token holders and returns a top-10 holder list. I took the addresses from that public index and, independently, made read-only BSC `eth_call` requests using `totalSupply()`, `balanceOf(address)` and `eth_getCode` at block 128,383,978. The ledger sample contains the sponsor’s publicly visible, date-labelled Q-series receipts (Oct 12–17); for each distinct listed transaction I required a successful mined receipt and decoded FLAPJAX `Transfer` events from the exact treasury address.

Scope limitation that matters: The 181-holder figure is a GoPlus index-reported count, not a self-enumerated full chain Transfer-log replay at block 128,383,978. The top-ten candidates were sourced from its most recently provided index and rebalanced against the chosen block. Thus I do not claim the exact-block total-holder count or rank completeness is independently proven; rapid DEX balances can change. The sponsor’s public list is also not mathematically guaranteed to include every historical payout.

Reproduction sources: GoPlus holder index; FlapJax’s published payout list; JSON-RPC https://bsc-dataseed.bnbchain.org; PancakeSwap v3 FLAPJAX / WBNB pool metadata; GoPlus field semantics. The pool pair token0/token1 identifiers were additionally checked by read-only public BSC calls: 0xca93ec685b8623688e6b236f9068034b298c2150 contains FLAPJAX/WBNB; 0x740a3b4a91cb8fa47e85d7f9713ca6ec2f8a037e contains BTCB/FLAPJAX; each reports fee tier 10000.

Verdict: MATCH for the inspected payout portion; global claim INCONCLUSIVE.

All 78 independently checked Q-series receipts below contain actual successful FLAPJAX transfers from this exact treasury, and their raw token amounts match the sponsor’s published nominal awards. Earlier VM5 original Q25 work independently confirmed the Oct 12/13 inbound buybacks from the pool to treasury and examined zero direct treasury→WBNB-pool FLAPJAX transfers within 126900000–127500000 via 123 complete contiguous public log queries (prior Q25 report).

However, “treasury only receives buybacks, pays bounties, and never sells into any pool, for all history” is NOT established by these bounded subsets. This distinction is a real evidence limit, not a pro-token endorsement.
